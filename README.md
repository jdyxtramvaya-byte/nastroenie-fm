# Настроение FM

Первая статическая версия сайта интернет-радио «Настроение FM».

## Что уже есть
- адаптивная главная страница для смартфонов и компьютеров;
- визуальный плеер и состояния интерфейса;
- четыре настроения: утро, поток, вечер и ночь;
- подготовленная структура для подключения настоящего аудиопотока.

## Важно
Сейчас это **макет интерфейса**, а не работающая радиостанция: аудиопоток ещё не подключён. GitHub Pages размещает сайт, но не передаёт звук круглосуточно. Для вещания понадобится отдельный разрешённый источник потока/радиосервер и музыка, лицензированная для интернет-трансляции.

## Публикация
Репозиторий использует GitHub Actions для публикации содержимого корня репозитория в GitHub Pages. В настройках репозитория открой **Settings → Pages** и выбери **Build and deployment → Source → GitHub Actions**, если это ещё не настроено.

После успешного workflow сайт будет доступен по адресу:
https://jdyxtramvaya-byte.github.io/nastroenie-fm/

## Следующий этап
1. Подключить Icecast/AzuraCast или другой легальный аудиопоток.
2. Подтянуть название текущего трека из API радиосервера.
3. Настроить живые эфиры через Mixxx и автоматическое возвращение к плейлисту.
